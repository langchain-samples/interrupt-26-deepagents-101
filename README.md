# Deep Agents 101

Workshop notebook for building a journal agent with the `deepagents` harness.

## Getting Started

Click the **Open in GitHub Codespaces** badge above, then wait for the Codespace to finish building. Your environment will be ready with all dependencies already installed via [uv](https://docs.astral.sh/uv/) — just open `deep_agents_101_journal_agent.ipynb` and start running cells.

The devcontainer:
- Uses Python 3.12
- Installs `uv` and runs `uv sync` on first launch
- Configures VS Code to use the `.venv` interpreter automatically
